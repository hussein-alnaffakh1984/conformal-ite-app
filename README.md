# Conformal Sensitivity ITE Explorer

تطبيق ويب تفاعلي يرافق ورقة *Online Conformal Sensitivity Analysis for Individual
Treatment Effects under Unmeasured Confounding and Temporal Distribution Shift*.

يحسب **فترات الأثر العلاجي الفردي (ITE)** مع ضمان توزيعي-حرّ، تحت اشتباه بمربِك
خفيّ (عبر معامل الحساسية Γ) وانجراف زمني (عبر التكيّف المتّصل α_t).

---

## ⚠ تنويه مهمّ

هذا **عرض بحثي توضيحي (research demo)** — **ليس أداة سريرية**.
- التغطية المعروضة **واقعية (factual)** وقابلة للقياس.
- تغطية ITE الحقيقية تُقاس **شبه-تخليقياً فقط** (كما تشرح الورقة).
- لا يُستعمل لاتخاذ قرارات علاجية.

---

## شنو يسوّي التطبيق

| المُدخَل | الوصف |
|---|---|
| بيانات | عيّنة سكّري جاهزة (800 صفّ حقيقي) **أو** ملفّ CSV ترفعه |
| Γ (جاما) | قوّة الاشتباه بمربِك خفيّ (1 = بلا مربِك) |
| α (ألفا) | مستوى الخطأ (0.10 = تغطية 90%) |

**المخرجات (3 تبويبات):**
1. **ITE intervals** — فترة الأثر لكل وحدة + نقطة التقدير.
2. **Sensitivity band** — كيف تتّسع الفترة وتتغيّر التغطية مع Γ (حادّ مقابل فضفاض).
3. **Online coverage** — كيف α_t يحافظ على التغطية رغم الانجراف الزمني.

**كل الحسابات تجري داخل متصفّحك — لا تُرفَع أي بيانات لأي خادم.**

### تنسيق ملفّ CSV المرفوع
- صفّ ترويسة فيه أسماء الأعمدة.
- عمود اسمه `A` (المعالجة: 0/1) وعمود اسمه `Y` (النتيجة: 0/1).
- بقيّة الأعمدة تُعامَل كمتغيّرات مشتركة رقمية (covariates).

## النشر على GitHub ثم Netlify

### الخطوة 1 — رفع الملفّات على GitHub
1. أنشئ مستودعاً جديداً (New repository) على github.com — مثلاً `conformal-ite-app`.
2. ارفع **محتويات هذا المجلّد** (مو المجلّد نفسه):
   - `index.html`
   - `diabetes_demo.csv`
   - `netlify.toml`
   - `README.md`
3. عبر الويب: زرّ **Add file → Upload files** ← اسحب الملفّات الأربعة ← **Commit**.

### الخطوة 2 — الربط بـ Netlify
1. ادخل [netlify.com](https://www.netlify.com) وسجّل بحساب GitHub.
2. **Add new site → Import an existing project → GitHub**.
3. اختر مستودع `conformal-ite-app`.
4. إعدادات البناء (تترك فارغة — موقع ثابت):
   - **Build command:** (فارغ)
   - **Publish directory:** `.`
5. اضغط **Deploy**.

خلال ثوانٍ يطلع لك رابط مثل `https://conformal-ite-app.netlify.app` — هذا تطبيقك المباشر.

### تحديث لاحق
أي تعديل ترفعه على GitHub، Netlify يعيد النشر تلقائياً.

## ملاحظة تقنية صادقة

الحدّ **الفضفاض (loose box)** محسوب بصيغته المغلقة (مطابق لنسخة Python تماماً).
الحدّ **الحادّ (sharp)** في هذا العرض يستعمل تقريب water-filling سريعاً للمتصفّح؛
النسخة المرجعية الكاملة (LP الدقيق عبر `scipy.linprog`) موجودة في كود البحث المرفق
بالورقة. الأرقام في التطبيق توضيحية للسلوك، والقيم البحثية النهائية تُعتمَد من كود Python.
